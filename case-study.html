The brief

During my software engineering internship at Intertech, I worked on a real-time bank identity verification system. The goal was to use computer vision techniques to support identity checks through face detection and image processing.

The project connected AI pipeline work with a REST API and mobile application context, making reliability, response time and clear integration boundaries important engineering concerns.

"The system needed to recognize and process identity information reliably while remaining suitable for real-time use."

Discovery & research

User interviews

I focused on the engineering requirements of a real-time verification flow: reliable detection, image preprocessing, pipeline performance and API integration. Key implementation areas included:

  • YOLO-based object and face detection for identity verification.
  • Image preprocessing before inference to improve pipeline consistency.
  • Real-time processing considerations for a responsive user flow.
  • REST API and mobile application integration requirements.

Heuristic audit

I debugged and optimized Python-based AI pipelines with a focus on performance and reliability. The work was completed within an Agile Scrum environment with sprint planning, stand-ups and retrospectives.

Existing dashboard with heuristic violations annotated during the audit phase.

Design strategy

Based on the research, I built the redesign around three principles:

Progressive disclosure

Show only what's needed for the current task. Advanced features revealed on demand, not upfront.

Opinionated navigation

Reduce the sidebar to 6 core items. Group secondary actions in context panels rather than global nav.

Goal-first onboarding

Replace the feature tour with a 3-step "send your first notification" flow that delivers an aha-moment in under 5 minutes.

Technical focus

Reliable computer vision pipeline

The central challenge was combining detection and preprocessing into a pipeline that could support real-time identity verification. The implementation required careful handling of image inputs, model inference and downstream API communication.

Integration and collaboration

The system was developed with a REST API and mobile application context. Agile Scrum ceremonies helped break the work into manageable increments and made it easier to surface integration and reliability issues early.

Performance and reliability

Debugging and optimization were part of the daily workflow. I used Python tooling and Git-based collaboration to improve the reliability of the AI pipeline and make the system easier to integrate.

Results

The project gave me practical experience taking computer vision work from model usage and preprocessing through to a real-time application context.

  • Detection: YOLO and computer vision techniques
  • Processing: AI-based face detection and image preprocessing
  • Integration: REST API and mobile application context
  • Engineering: Python debugging, optimization and Git collaboration

"This project connected computer vision, backend integration and real-world reliability requirements in one practical system."

Reflections

The biggest lesson from this project was that AI quality is only one part of a usable system. Preprocessing, response time, integration boundaries and debugging discipline all matter when a model becomes part of a real application.
