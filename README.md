# Abdulkadir Partal Portfolio
Personal portfolio for Abdulkadir Partal, a software engineer focused on artificial intelligence, computer vision, backend development, full-stack applications and embedded systems.

## Run locally

No package installation is required. From this directory, run:

```powershell
python -m http.server 5500
```

Then open http://localhost:5500/index.html.

## Pages

- `index.html`: Profile, technical expertise, experience, projects and contact
- `projects.html`: Filterable project list
- `case-study.html`: Bank identity verification project case study
- `blog.html`: Technical writing index
- `blog-article.html`: Computer vision article
